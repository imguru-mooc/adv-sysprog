C5-1 Blocking vs Non-Blocking

읽을 Data가 없는 Pipe에 read()를 호출하면 무슨 일이 일어나는지, Blocking과 Non-blocking에서 Process의 상태와 CPU 사용이 어떻게 다른지 비교합니다.

C5-2 select / poll 동작

select와 poll은 호출할 때마다 목록 전체를 Kernel에 넘기고, Kernel은 전부 검사합니다. Event 하나를 처리하는 데 드는 작업량을 오른쪽 Counter로 확인하세요.

C5-3 epoll: Interest List와 Ready List

epoll은 관심 목록을 Kernel 안에 보관하고, Event가 발생하면 Callback이 Ready List에 추가합니다. FD 수와 Ready 수를 바꿔 가며 작업량이 무엇에 비례하는지 확인하세요.

C5-4 Level Trigger vs Edge Trigger

Pipe에 "HELLO LINUX"가 들어 있습니다. epoll_wait가 return할 때마다 3Byte씩 읽으면 Level Trigger와 Edge Trigger에서 무슨 일이 일어나는지 비교합니다. 아래의 "직접 해 보기"에서 버튼을 마음대로 눌러 보세요.

C5-5 하나의 Event Loop

timerfd, eventfd, signalfd, inotify가 하나의 epoll에 등록되어 있습니다. 성격이 전혀 다른 네 가지 Event가 같은 경로(Kernel 객체 → Callback → Ready List → epoll_wait → Handler)로 처리되는 것을 확인하세요.
