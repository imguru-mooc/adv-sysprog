C8-1 Capability 검사

Kernel의 권한 검사는 "root인가"가 아니라 "이 Capability가 Effective 집합에 있는가"입니다. root, 일반 사용자, File Capability, 그리고 초기화 후 권한을 내려놓는 과정을 비교합니다.

C8-2 seccomp Filter

System Call은 실행되기 전에 seccomp Filter(BPF Program)를 지납니다. Filter의 결정에 따라 실행되거나, 오류 Code만 받거나, Process가 죽습니다. 마지막 Scenario는 io_uring이 Filter를 지나지 않는 이유입니다.

C8-3 Namespace

같은 Kernel 위에서 Process마다 "보이는 세계"가 다릅니다. 같은 Process가 Host에서는 4021번, Namespace 안에서는 1번입니다. Kernel은 하나이고, 묻는 Process에 따라 다른 답을 돌려줄 뿐입니다.

C8-4 Cgroup

Cgroup은 Process의 묶음에 "얼마나 쓸 수 있는가"를 정합니다. 위쪽 Scenario로 CPU Throttling, Memory 한도 초과, Process 수 한도를 단계별로 보고, 아래쪽 "직접 해 보기"에서 CPU Limit과 Memory Limit Slider를 움직여 보세요.
