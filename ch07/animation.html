C7-1 /proc의 동작

/proc의 File은 Disk에 없습니다. 읽는 순간 Kernel이 자신의 자료 구조를 들여다보고 문자열로 만들어 줍니다. 그리고 top이 보여 주는 CPU%는 어디에도 저장되어 있지 않은 값입니다.

C7-2 ptrace: strace와 gdb의 동작 원리

strace, ltrace, gdb는 모두 ptrace라는 Kernel 기능 위에 있습니다. 대상 Process를 멈추고, 들여다보고, 다시 실행시킵니다. 그래서 강력하고, 그래서 비쌉니다.

C7-3 perf Sampling

perf는 일정 간격으로 CPU를 멈춰 "지금 어느 함수였나"를 기록합니다. Sample이 쌓이면 시간의 분포가 드러납니다. Step 하나가 Sample 묶음 하나입니다.

C7-4 ftrace의 동작 원리

Kernel 함수 5만 개를 추적할 수 있는데 평소 Overhead는 0입니다. 함수 첫머리의 nop을 실행 중에 바꿔 쓰는 Dynamic ftrace와, 같은 원리의 Tracepoint를 봅니다.

C7-5 eBPF의 동작

bpftrace Script가 Kernel 안에서 실행되기까지의 과정(Compile → Verifier → JIT → Attach)과, Event가 발생할 때마다 Kernel 안에서 집계가 이루어지는 흐름을 봅니다.
