C3-1 read() / write() Path

read()와 write()가 Kernel의 어느 층까지 내려갔다가 돌아오는지, Page Cache에 Data가 있을 때와 없을 때를 비교합니다.

C3-2 VFS Dispatch

같은 read(fd, buf, n)이 대상에 따라 서로 다른 구현으로 연결됩니다. fd → struct file → f_op까지는 공통이고 그 다음에 갈라집니다.

C3-3 Page Cache Simulator

File의 Block 8개와 Page 4개짜리 작은 Page Cache(LRU)입니다. Step 하나가 read() 한 번입니다. 같은 Block을 다시 읽을 때, Cache보다 넓게 읽을 때, 순차로 읽을 때를 비교하세요.

C3-4 Buffered / Direct / mmap 경로 비교

같은 File의 같은 위치를 두 번 읽습니다. 세 방식에서 Data가 지나는 경로, CPU에 의한 복사 횟수, System Call 횟수가 어떻게 다른지 비교합니다.

C3-5 Writeback과 fsync

write()한 Data가 Page Cache의 Dirty Page를 거쳐 Disk 매체에 도달하기까지. write만 했을 때, fsync, fdatasync, Background Writeback을 비교하고 각 시점에 전원이 꺼지면 어떻게 되는지 확인합니다.
