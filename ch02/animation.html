C2-1 Process Address Space Explorer

malloc, 재귀 호출, 큰 할당이 Process의 주소 공간(VMA)을 어떻게 바꾸는지, 그리고 VSZ와 RSS가 왜 다르게 움직이는지 확인합니다.

C2-2 Virtual Address Translator

Virtual Address를 입력하면 4-Level Page Table을 따라 Physical Address로 변환되는 과정을 단계별로 보여 줍니다. TLB Hit와 Miss를 바꿔 비교하세요. (Physical 쪽 숫자는 설명을 위한 가상의 값입니다)

C2-3 TLB Hit / Miss Simulator

Entry 4개짜리 TLB(LRU 교체)에 Memory 접근을 하나씩 넣어 봅니다. Step 하나가 Memory 접근 한 번입니다. 접근 Pattern에 따라 Hit Rate가 어떻게 달라지는지 비교하세요.

C2-4 Page Fault Walkthrough

Memory 접근이 Page Fault가 되고, Kernel이 VMA를 보고 판단해 처리한 뒤 같은 명령을 다시 실행하기까지. 네 가지 경우를 비교합니다.

C2-5 mmap: File ↔ Page Cache ↔ Address Space

같은 File을 Mapping한 Process 두 개, Page Cache, Disk를 한 화면에서 봅니다. MAP_SHARED와 MAP_PRIVATE에서 쓰기가 어디까지 전달되는지 비교하세요.
